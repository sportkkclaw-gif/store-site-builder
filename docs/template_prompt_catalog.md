# StoreSite Builder｜30 套模板 AI 視覺生成 Prompt Catalog

## 共用 AI 圖像生成規格
【通用用途】
這不是單純藝術插畫，而是給「模板選擇頁」使用的模板主視覺圖。
圖像要像：
- 高質感網站模板提案圖
- Behance / Dribbble 作品封面
- 品牌官網概念視覺
- 官網設計作品展示圖

【通用構圖要求】
1. 主畫面要像一個完整品牌官網的視覺提案。
2. 要有網站感：可暗示 desktop layout、hero area、product section、CTA、mobile preview。
3. 不要做成一般 UI 小卡片。
4. 不要只做灰條骨架圖。
5. 不要做成純色塊。
6. 要有品牌情緒、情境物件、商品氛圍。
7. 視覺主角可以是：官網畫面 + 商品情境 + 品牌配色 + 提案式構圖。
8. 可加入少量簡單可讀文字，但不要依賴大量文字。
9. 不可出現亂碼文字。
10. 不可出現浮水印、Logo 侵權、素材網站標記。

【通用風格要求】
- polished, premium, high-end, visually appealing
- editorial composition
- productized website concept art
- commercial quality
- beautiful lighting
- clean depth hierarchy
- strong brand identity
- no watermark
- no gibberish text
- no chaotic collage
- no cheap stock look

【圖像比例建議】
- 4:5 為主
- 或 3:4
- 統一建議使用 4:5，方便模板畫廊展示

【通用負面要求】
- no watermark
- no distorted UI
- no garbled text
- no generic skeleton layout
- no plain placeholder blocks only
- no low-effort wireframe
- no copyright logos
- no messy composition

【建議輸出命名格式】
industry-slug-name
例如：
drink-matcha-hiyori
restaurant-golden-banquet
cafe-nordic-morning
