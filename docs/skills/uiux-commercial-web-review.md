# uiux-commercial-web-review

## 目的

此 Skill 用於檢查與改善商業網站、模板展示頁、Landing Page、Builder Preview、桌機版與手機版 UIUX 品質。

此 Skill 不處理後端、不處理資料庫、不處理金流、不處理部署。
此 Skill 專注於：

- 視覺設計
- 使用者體驗
- 商業化展示
- 模板吸引力
- 桌機 / 手機版面品質
- 是否可正式展示給客戶

---

## 使用時機

當任務涉及以下任一項時，必須使用本 Skill：

1. 首頁設計
2. Landing Page
3. Template Gallery

5. Builder Preview
6. Fullscreen Preview

8. 手機版 Hero

10. 商品卡片
11. 菜單區
12. 聯絡資訊區
13. CTA
14. 導覽列
15. 商業化視覺驗收

## 核心原則

一個可商業化的網站畫面必須滿足：

1. 一眼看起來是正式產品，不是測試畫面。
2. 視覺有層次，不是圖片與卡片硬塞。
3. 桌機版與手機版都要成立。
4. Hero 必須有主視覺焦點。
5. CTA 必須清楚。
6. 背景必須有設計渲染。
7. Section 之間要有節奏。
8. 圖片不能像 placeholder。
9. 不可出現假 UI、假按鈕、假導航。
10. 使用者看了會想使用，而不是覺得還在開發中。

---

## 桌機版檢查標準

桌機版是商業展示的主場，必須嚴格檢查。

### Hero

Hero 必須符合：

- 圖片不破圖
- 圖片不過度放大
- 圖片裁切合理
- Hero 高度合理
- 左右留白合理
- 文字卡與圖片比例協調
- CTA 明顯
- 不像圖片預覽器
- 不像單純大圖卡
- 可直接展示給客戶

不合格情況：

- Hero 圖片被切掉主體
- 圖片塞太滿
- 文字卡壓住圖片重點
- 左右空白過大
- 背景只是純色
- 圖片與內容沒有整合
- 看起來像測試頁

---

## 手機版檢查標準

手機版必須符合：

- 390 / 375 / 320 無水平破版
- Hero 文字不超出
- CTA 可見
- 圖片不爆版
- 內容不被瀏覽器底部遮住
- 表單可操作
- Preview 可返回
- Scroll 流暢

---

## Template Gallery 檢查標準

模板作品牆必須：

- 圖片吸引人
- 分類清楚
- 卡片大小一致
- 目前使用中狀態清楚
- CTA 明確
- 不像 placeholder
- 不像隨機 AI 圖
- 不出現假 UI / 假按鈕 / 假導覽列

---

## 模板主視覺圖片標準

模板圖片必須是：

- 商業化主視覺
- 品牌形象圖
- 商品攝影感
- 氛圍照
- 可作為正式模板封面

禁止：

- 幾何拼貼
- 假網站截圖
- 假 navbar
- 假按鈕
- 假 icon
- 假手機 App
- 假瀏覽器 UI
- 低質 placeholder

---

## 背景渲染標準

背景不可以只是純色或大空白。

應具備：

- palette-based background
- gradient
- soft glow
- section layering
- shadow
- texture
- depth
- visual continuity

不合格：

- 純色平鋪
- 大片空白
- 圖卡硬貼
- section 斷裂
- 背景與圖片不搭

---

## Section 檢查標準

### 品牌故事

必須像正式品牌敘事區，不是單純文字卡。

### 招牌商品

必須像商品展示區，不是 placeholder 卡片。

### 菜單

必須像正式菜單，不是表格或後台清單。

### 門市資訊

必須像 contact section，不是資料表。

---

## CTA 檢查標準

CTA 必須：

- 可見
- 可點
- 文案明確
- 對應正確行為
- 不誤導使用者

例如：
- 有地圖才可顯示「查看地圖」
- 沒地圖時應使用「查看菜單」或「了解店家」

---

## 導覽列檢查標準

導覽列項目必須可點擊並滾動到對應區塊。

例如：

- 品牌故事 → brand-story
- 招牌商品 → featured-products
- 菜單 → menu
- 門市 → store-info / contact

如果區塊不存在，導覽列不應顯示該項目。

每次 UIUX 任務完成後，必須回報：

1. 桌機版是否通過
2. 手機版是否通過
3. Hero 是否通過
4. 背景渲染是否通過
5. Section 是否通過
6. Template Gallery 是否通過
7. CTA 是否通過
8. 導覽是否通過
9. 是否有 P0 / P1 / P2
10. 是否可送 Jason 驗收

---

## P0 / P1 / P2 判定

### P0

- 頁面無法使用
- 預覽壞掉
- 手機版嚴重破版
- ZIP / export 壞掉
- 圖片消失
- CTA 完全不能用

### P1

- 桌機版 Hero 破圖
- 模板圖像不商業化
- 導覽列看起來可點但不能用
- 表單驗證不足
- 背景像 placeholder
- 主要流程會誤導使用者

### P2

- 文案可更順
- spacing 可更好
- hover 狀態可加強
- 小尺寸細節可優化

## StoreSite Builder 桌機視覺修正補充

針對店名片 / StoreSite Builder 的模板、Preview、作品牆與 Landing Page：

1. 桌機版 Hero 建議 max-width 1180–1280px，min-height 520–680px，max-height 不超過 760px。
2. Hero image 不可無限制放大，不可超出 hero boundary。
3. 使用 `object-fit: cover` 時必須搭配安全裁切、圓角、遮罩或容器約束。
4. 背板需有 palette-based gradient、soft glow、section continuity、card depth。
5. Featured / Menu / Brand Story / Store Info 都要像商業 landing page 的正式區塊，不可像後台表單或 placeholder 卡片。
6. 手機版若已可接受，桌機修正時不可大改手機結構；只做 390/375/320 回歸。

---

## 最終判斷標準

此 Skill 的最高判斷標準是：

這個畫面能不能直接拿給小店家看，讓他覺得這是一個正式、可靠、值得使用的產品？

如果不能，就是不通過。
